# The Desk Implementation Plan

**Goal:** One time-aware NQ/MNQ dashboard with an account guard, signalling only setups that passed a pre-registered backtest.

**Architecture:** Pure strategy functions shared by the backtest and the live server; a pure `buildState` that turns clock + bars + journal + settings + verdicts into the page state; thin Express and a plain page.

**Tech stack:** Node 18+, Express, node:test, plain HTML/CSS/JS, canvas chart, MV3 extension.

**Spec:** `docs/superpowers/specs/2026-11-19-the-desk-design.md`, `research/PREREGISTRATION.md`

## Global constraints
- 1 NQ point cost per trade; closed bars only; stop-first; MNQ $2 per point; $250 risk; two losses; $500 daily stop.
- Lucid $50K: $2,000 max loss limit, end-of-day trailing, locks at $50,100.
- Design: #05060A ground, 1px lines, Outfit + IBM Plex Mono, no glow, no icons, no game elements; motion off under prefers-reduced-motion.

## Review focus
- A bar still forming must never produce or change a signal.
- A signal must not appear when the feed is stalled, or when the guard is locked.
- Clock-change weeks: every window edge, US and UK.
- Evening trades count toward the next trading day.
- Journal input that is not a number; a stop of zero; a stop too wide for one contract.
